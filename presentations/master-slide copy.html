Experiment 10: Cache Pinning Worked, But Retention Was Inconclusive

Validation confirmed end-to-end cache pinning, but sweep behavior did not support a clean pinned-retention win under pressure.

Setup
  • Purpose: test whether nvext.cache_control improves replay retention.
  • Workload: compare off versus ephemeral:1h at matched distractor counts.
  • Stack requirement: custom cache-pinning branches: Dynamo PR #6213 and SGLang PR #18941.
  • Validation: router pin spawned and worker pin applied.
  • Observation: replay latency rose sharply under pressure, consistent with thrash-like behavior.
  • Outcome: the sweep remained inconclusive despite a live pin path.
Protected Hint JSON
{
  "nvext": {
    "cache_control": {
      "type": "ephemeral",
      "ttl": "1h"
    }
  }
}
Replay Latency Results

Control replay jumps sharply after 60 distractors; protected replay stays lower, but the overall sweep was still classified as inconclusive.
